## 📋 Descrição do Projeto (PT-BR)

Este projeto é uma aplicação mobile desenvolvida em Flutter com foco educacional para praticar conceitos fundamentais do desenvolvimento de aplicativos.

O sistema permite que usuários realizem cadastro e login, organizem tarefas diárias através de um calendário e acompanhem suas atividades por meio de uma dashboard personalizada.

O objetivo foi aplicar conceitos de navegação entre telas, gerenciamento de estado, armazenamento local de dados e construção de interfaces gráficas utilizando Flutter e Dart.

## 🚀 Funcionalidades

✔ Cadastro de usuários

✔ Login de usuários

✔ Dashboard personalizada

✔ Calendário interativo

✔ Cadastro de tarefas por data

✔ Remoção de tarefas

✔ Marcação de tarefas como concluídas

✔ Organização automática das tarefas

✔ Armazenamento local utilizando SharedPreferences

✔ Separação de tarefas por usuário

# 📅 Task Manager — Flutter Study Project

## 📋 Project Description (EN)

This project is a mobile application developed with Flutter for educational purposes, focusing on practicing fundamental mobile development concepts.

The system allows users to register, log in, manage daily tasks through a calendar and monitor activities using a personalized dashboard.

The main goal was to apply concepts such as screen navigation, state management, local data persistence and UI development using Flutter and Dart.

## 🚀 Features

✔ User registration

✔ User login

✔ Personalized dashboard

✔ Interactive calendar

✔ Daily task management

✔ Task deletion

✔ Task completion tracking

✔ Automatic task organization

✔ Local data storage using SharedPreferences

✔ User-specific task separation
